# SDK Reference

This is the SDK reference for the [NEOPILOT CLI & Core SDK](https://github.com/khulnasoft-lab/neopilot), [Code Interpreter SDK](https://github.com/khulnasoft-lab/code-interpreter), and [Desktop Sandbox SDK](https://github.com/khulnasoft-lab/desktop).

The reference is intended to be limited to low-level descriptions of various programmatic functionality. If you’re just getting started with NEOPILOT, we would instead recommend looking at the [documentation](/docs) first or to get started quickly with an example.
