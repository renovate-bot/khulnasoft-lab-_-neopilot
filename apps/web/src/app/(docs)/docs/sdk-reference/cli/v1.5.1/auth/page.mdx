## neopilot auth


authentication commands

### Usage

```bash
neopilot auth [options] [command]
```
## neopilot auth login


log in to CLI

### Usage

```bash
neopilot auth login [options]
```


## neopilot auth logout


log out of CLI

### Usage

```bash
neopilot auth logout [options]
```


## neopilot auth info


get information about the current user

### Usage

```bash
neopilot auth info [options]
```


## neopilot auth configure


configure user

### Usage

```bash
neopilot auth configure [options]
```
