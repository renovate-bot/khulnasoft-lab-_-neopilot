# Installing beta SDKs

To use features like [sandbox persistence](/docs/sandbox/persistence) and [metrics](/docs/sandbox/metrics), you need to install the beta version of the SDKs.

### Code Interpreter SDK

<CodeGroup>
```bash {{ language: 'js' }}
npm i @neopilot/code-interpreter@beta
```

```bash {{ language: 'python' }}
pip install neopilot-code-interpreter==1.2.0b5
```
</CodeGroup>

### Core SDK

<CodeGroup>
```bash {{ language: 'js' }}
npm i neopilot@beta
```

```bash {{ language: 'python' }}
pip install neopilot==1.2.0b6
```
</CodeGroup>

### Desktop SDK

<CodeGroup>
```bash {{ language: 'js' }}
npm i @neopilot/desktop@beta
```

```bash {{ language: 'python' }}
pip install neopilot-desktop==1.7.1b1
```
</CodeGroup>
